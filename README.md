# MotionZync

MotionZync is a web platform for browsing, previewing, customizing, and learning from CSS and JavaScript animations.

## Core areas
- Home
- Gallery
- Playground
- Animation details
- Compare
- Tools
- Course / learning
- Favorites
- Admin animation management

## API-key settings
The API-key settings UI and local encrypted key vault remain available for optional provider configuration. Keys are encrypted in the browser and are not stored in the MotionZync backend.

## Development
```bash
npm install
npm run dev
npm run build
```

Production builds use Vite and output to `dist/`.

See `.env.example` for configuration placeholders.
