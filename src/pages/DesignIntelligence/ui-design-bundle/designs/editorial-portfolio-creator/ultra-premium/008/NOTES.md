# Longform article reader — Collaborative Advanced

- **ID:** `ultra-editorial-portfolio-creator-008`
- **Category:** editorial-portfolio-creator (Editorial, blogs, portfolios, creator pages and publishing)
- **Tier:** Ultra Premium+ (library access label only — no entitlements in this bundle)

- **Density:** default | **Tone:** social

## Design rationale
Longform article reader for editorial, blogs, portfolios, creator pages and publishing, expressed as a single wide editorial column with pull-quotes and reading rhythm in the "Collaborative" variant. Advanced information architecture: layered panels, refined interaction states, configurable density and purposeful, reduced-motion-aware choreography.

## Responsive behavior
Fluid CSS grid; below 48rem the composition collapses to a single column, split panes stack, topbar nav links collapse behind the menu button. Touch targets are ≥ 2.5rem.

## Accessibility notes
Semantic landmarks (nav/main/table/article), labelled controls, visible focus rings via `--mz-focus`, status shown with text plus color, reduced-motion media query disables all transitions. Sample data is fictional.
